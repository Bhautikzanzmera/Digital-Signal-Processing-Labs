# Digital Signal Processing Labs (MATLAB)

A collection of **4 DSP lab assignments** implemented in **MATLAB Live Scripts (.mlx)** with required datasets (.mat).

## Contents
- **Lab01**: DSPlab_01_student.mlx
- **Lab02**: DSPlab_02_student.mlx
- **Lab03**: DSPlab_03_student.mlx + datasets (DSPlab_03_student.asv, DSPlab_03_bowie_interference)
- **Lab04**: DSPlab_04_student.mlx + datasets (DSPlab_04_student.asv, DSPlab_04_bowie)

## How to Run
1. Open MATLAB
2. Open any `.mlx` file inside its Lab folder
3. Keep required `.mat` files in the same folder (For lab 3 and 4)
4. Run the sections in order
